### About the Experiment 

This experiment focuses on designing and simulating an IoT dashboard for real-time remote monitoring.  
It demonstrates how sensor data stored on cloud platforms can be visualized using charts, graphs, and indicators.  
Students learn concepts of data fetching through APIs and dynamic web-based visualization.  
The experiment introduces dashboard design principles and user-interface integration in IoT systems.  
The simulation provides practical understanding of remote monitoring and data-driven decision support systems.
